# FH4Droid 0.9.10

Available for ARM64 phones running Android 13 or newer.

- **Clearer performance overlay.** F3 shows game FPS and displayed FPS separately. See how many frames were dropped or repeated recently and across the session.
- **Trainer in the game menu.** See the active save and any pending restart. **Add credits** adds 100,000, 1 million or 10 million credits to the active modded save while the trainer is running. **Set credits** enters a new balance. **Fast travel anywhere** is an experimental toggle for the free-roam map.
- **Quick Playthrough.** Open **More → Mods & DLC → Mods** to enable it. It sets half prices for base-game cars and upgrades and triple Festival pacing rewards. The next launch uses the modded save. Open **Festival pacing** to fine-tune or disable it.
- **Experimental FSR 3 frame generation.** Open **Settings → Graphics → Display → Frame generation** and select **FSR 3 (experimental)**, then restart the game. It is off by default. Test with SDR, a 120 Hz display, and a steady 60 FPS target. The F3 overlay shows when it is generating frames and why it may be waiting or unavailable. Generated frames smooth motion at the existing game and input rate.

Android device testing for FSR 3 and fast travel is pending.
