# FH4Droid r7 refinement review

This is the disposition of all 70 selected items, plus Xclipse/Mali support requested afterward. **Implemented does not mean physically tested.** No Android phone or raw playable game is attached to this workspace. The white-car image and remaining audio/memory warnings are unresolved. Research features without verified guest hooks or a service are withheld rather than exposed as empty controls.

The minimum is **Android 12 / API 31**, as requested. The build uses ARMv8-A. Vulkan 1.1/1.2 paths are experimental and require the listed features; Vulkan version and GPU family alone do not establish gameplay support.

## Xclipse and Mali reference review

Detect Samsung/Xclipse names including AMD vendor-ID presentations; recommend system Vulkan. ARM Mali/Immortalis guidance is separate. Turnip controls stay Qualcomm-only. PT4Droid pinned reference uses a different renderer, requires Vulkan 1.3 and calls Mali/Xclipse experimental; its PanVK RC3 metadata requires API35 and exact GPU/kernel compatibility, so it is not bundled as a universal Android12 Mali driver.

## Device gate after installation

1. Record the phone, SoC/GPU, RAM, Android version, exact system/imported driver and app version. Run the basic driver test, then test actual gameplay separately.
2. At identical settings, compare system and compatible imported drivers. In Autoshow, keep the same car/colour/camera and compare bloom on/off, then reflections and renderer path one change at a time. Mark the visual issue and attach an external screenshot plus report.
3. Test 50%, 59%, 67%, 90% and 100% after fresh launches in driving and Autoshow. Check horizontal seams, paint, menus and HUD proportions at both original and wide layout.
4. Open/close pause, map, car views and short dialogs repeatedly; background/resume, open the editor, rotate the phone, reconnect a controller and switch input devices. Look for shrinking/sidebars and held inputs.
5. Test remapped controls, arrows/stick, both arrows together, analog pedals, per-control Always visible and menu Confirm/Back. Test Save/Cancel, undo/redo and restoring a graphics profile.
6. Export Normal and Modded separately, then Both. Restore only against disposable copied saves first. Test Xenia import using a copied base-game profile, keeping an independent backup.
7. Listen to engine, radio, ambience and external music; drive the same route for at least 15 minutes for heat/RAM/pacing. Export the current report. These steps qualify one configuration, not every phone in a GPU family.
